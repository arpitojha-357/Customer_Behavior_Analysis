## 📌 Overview

This project demonstrates the complete **data analytics lifecycle**, from loading and cleaning raw data to performing SQL analysis and creating interactive dashboards.

The goal is to identify important trends, generate business insights, and present findings through a professional report and presentation.

## 📂 Dataset

The project uses a **CSV dataset** containing business-related records.

The dataset was explored, cleaned, and prepared for further analysis using Python, SQL, and Power BI.

## 🔍 Project Steps

### 1️⃣ Data Loading

* Imported the dataset into Python using Pandas.
* Examined rows, columns, and data types.
* Reviewed the overall structure of the dataset.

### 2️⃣ Exploratory Data Analysis (EDA)

* Analyzed descriptive statistics.
* Identified missing values and duplicate records.
* Examined unique values and data distributions.
* Explored relationships between important variables.
* Identified initial business patterns and trends.

### 3️⃣ Data Cleaning

* Handled missing values.
* Removed duplicate records where necessary.
* Corrected data types and formatting.
* Standardized inconsistent values.
* Prepared a clean dataset for further analysis.

### 4️⃣ SQL Analysis

* Imported the cleaned dataset into a relational database.
* Created tables and verified the data.
* Wrote SQL queries to answer business questions.
* Used filtering, grouping, sorting, joins, and aggregate functions.
* Analyzed key metrics and business performance.

### 5️⃣ Power BI Dashboard

* Connected Power BI to the cleaned dataset/database.
* Created relationships between tables where required.
* Developed DAX measures for key performance indicators.
* Designed interactive charts, tables, and KPI cards.
* Added slicers and filters for better data exploration.

### 6️⃣ Report & Presentation

* Prepared a professional business report.
* Documented the analysis and key findings.
* Created a presentation using Gamma.
* Summarized insights and business recommendations.
